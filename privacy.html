MeshCore One Stop

Privacy policy

Last updated November 12, 2026. This policy matches the current build of the app, sideload version 99.1.6, package com.cbhb.meshcoreonestop.

MeshCore One Stop is published for the Columbia Basin Honey Badgers (C.B.H.B.). Questions go to github.com/thescrawler.

The short version

The app does not ask you to create an account. It talks to your MeshCore radio over Bluetooth, USB, or TCP. Your messages stay on the mesh through that radio. They are not sent to a C.B.H.B. server.

Map layers can download public feeds and keep the last good download on the phone. Names you set in My Devices, device logs, settings, and a repeater password you choose to save stay on the phone. The app has no affiliate ads.

No account

There is no sign-in, no C.B.H.B. user account, and no account database. We do not ask for your name, email address, or phone number inside the app.

Your radio and your messages

The app connects to the radio you pair or address yourself:

  • Bluetooth
  • USB
  • TCP

Chat and other off-grid messages go through that connection onto the mesh. C.B.H.B. does not receive a copy. If the phone is not connected to the radio that way, the app is not carrying those messages.

Map layers and public feeds

Map and status layers are separate from mesh chat. They can download public feeds:

  • MeshCore nodes
  • Meshtastic nodes
  • FT8, when you ask for it (on demand, not by itself)
  • Winlink reports sent from WINLINK to APWL2K

The phone stores the last good download of those feeds so you can open it again. Those are other people’s public radio reports, not a private profile of you.

When the phone downloads a public feed, that site can see the phone’s internet address, the same way any website can. C.B.H.B. does not receive that address in an account record, because there is no account.

My Devices and telemetry

Opening My Devices, or pulling down to refresh, shows the last saved readings and does not radio the repeater. Voltage, and the trend of that voltage, are read when you open a device and tap Request status. The app does not poll for telemetry in the background.

Battery percent shown in the app is estimated from voltage on the phone. It is not sent off as its own report.

Names, logs, and exports

Local display names, such as “C.B.H.B. Node (1)” or “C.B.H.B. Node (Patterson)”, stay on the phone. They do not change the name the radio sends on the air.

Per-device logs stay on the phone. If you export a CSV, that file is created for you. Exporting it does not upload it to C.B.H.B.

A settings export leaves out passwords and the private key.

Repeater admin password

If you save a repeater admin password, it is stored on the phone so the app can use it for command-line and radio settings, including a retune of a repeater you own. It is not included in a settings export. C.B.H.B. does not keep a server copy.

Retune asks you to confirm, and the radio reboots. Companion retune is a separate choice in that same step and does not change transmit power. That action stays between the app and the radio you are connected to.

Ads

The app does not show affiliate ads. An upstream store banner that used to be in the project was removed. We do not sell advertising space in the app and we do not sell personal information.

What this policy does not add

This policy describes the behavior above. It does not add tracking, an account, a newsletter, or other collection. If a later build starts handling information differently, this page will be updated and the date at the top will change.

How long data stays

Names, logs, cached map downloads, settings, and any saved repeater password remain on the phone until you delete them, clear the app’s storage, or uninstall the app. C.B.H.B. has no account copy to erase, because no account is created.

Children

MeshCore One Stop is a tool for people using their own mesh radio. It does not create an account, and it is not built to collect information about children. We do not knowingly collect personal information from children.

This website

The C.B.H.B. website is a set of plain pages. It does not ask you to sign in. It does not run analytics. It does not use tracking cookies, and it does not show a cookie banner because it does not set those cookies.

The node map page loads the public MeshCore map from map.meshcore.io inside the page, and links to that map. That map is a separate site. Your browser talks to it directly when the page is open. This website does not keep a copy of node positions.

aprs.fi Mesh Tools is a separate browser add-on. Its own data notes are in that project’s guide: Privacy and data sources.

Changes

If this policy changes, the new text will be posted on this page with a new date.
