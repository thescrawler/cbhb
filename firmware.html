MeshCore radios

Firmware

These images are C.B.H.B. builds on top of MeshCore v1.18.0. Use the files on this page, not a copy sent by someone else.

Supported boards. Seeed XIAO nRF52840 + Wio-SX1262 (available now). RAK4631 WisBlock (RAK19003 base) and Heltec T096 (builds coming). Each file is built for one of those boards, and is labeled with that board’s name.

Test builds

Repeater v1.18.0-jp.wdt2 and companion+repeat v1.18.0-jp.crep1 for the Seeed XIAO nRF52840 + Wio-SX1262 have not been tested on radio hardware yet. Bench-test on a spare Seeed XIAO nRF52840 + Wio-SX1262 first. What changed is on the release notes page. The matching Android app is One Stop 99.1.7.

Flash notes

  • Seeed XIAO nRF52840 + Wio-SX1262 (UF2). Double-tap the reset button on the Seeed XIAO nRF52840 so it shows up as a drive, then copy the .uf2 file onto it. The Seeed XIAO nRF52840 filesystem is not erased.

When RAK4631 WisBlock (RAK19003 base) and Heltec T096 builds are posted, each one will have its own file and flash steps, named for that board.

Defaults

Companion+repeat, jp.crep1

  • Repeat is off until you turn it on, or until One Stop’s Camp Mode switch turns it on.
  • Logger is on, every 15 minutes, 256 records.
  • Solar is set to auto. If no INA3221 is present, solar sampling stays quiet.
  • Bluetooth pairing PIN is 123456. On the Seeed XIAO nRF52840 + Wio-SX1262 the name is MeshCore- plus the node name.

Repeater, jp.wdt2

  • Repeat is on. This is a repeater.
  • Logger is on, every 15 minutes, 256 records.
  • Solar is set to auto and uses an INA3221 when one is found. If the chip does not answer, those fields stay at zero for that sample.
  • USB serial is 115200. Bluetooth is a Nordic UART named RPT- plus the node name. Pairing PIN is 123456. After you pair, log in with your admin password before using the commands below.

Commands

These text commands work on both jp.wdt2 and jp.crep1 for the Seeed XIAO nRF52840 + Wio-SX1262. On the companion, send them over the companion link. On the repeater, use USB serial or the Bluetooth CLI after login.

ver
get repeat
set repeat on
set repeat off
get logger
set logger on
set logger off
set logger.interval 15
logger latest
logger page 0
logger clear
get solar
set solar auto
set solar on
set solar off
solar
get watchdog
power
stats-core
stats-radio
stats-packets

logger page 0 is the newest record. set logger.interval is in minutes.
