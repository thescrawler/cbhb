MeshCore radios

Firmware

These images are C.B.H.B. builds on top of MeshCore v1.18.0. Use the file named for your board, not a copy sent by someone else, and not a file built for a different board.

Supported boards. Seeed XIAO nRF52840 + Wio-SX1262, RAK4631 WisBlock (RAK19003 base), and Heltec T096. Each file is built for one of those boards, and is labeled with that board’s name.

Test builds

Repeater v1.18.0-jp.wdt2, companion+repeat v1.18.0-jp.crep1, and companion+room v1.18.0-jp.croom1 have not been tested on radio hardware yet. Bench-test on a spare board of the same type first. What changed is on the release notes page. The matching Android app is One Stop 99.1.7.

Flash notes

On every supported board, double-tap the reset button so the board shows up as a drive, then copy the matching .uf2 file onto it. The filesystem (identity and prefs) is not erased by a UF2 update.

  • Seeed XIAO nRF52840 + Wio-SX1262 (UF2). Double-tap reset on the Seeed XIAO nRF52840, then copy the Seeed XIAO nRF52840 + Wio-SX1262 file.
  • RAK4631 WisBlock (RAK19003 base) (UF2). Double-tap reset on the RAK4631 WisBlock, then copy the RAK4631 WisBlock file.
  • Heltec T096 (UF2). Double-tap reset on the Heltec T096, then copy the Heltec T096 file.

Defaults

The compiled default frequency on all of these images is 869.618 MHz, until you change it in the app or with set freq.

Companion+room, jp.croom1, RAK4631 WisBlock

  • The companion identity and the room identity are separate. Clients see the room as its own node.
  • The room is off until you turn it on with set room on. Turn it off with set room off.
  • The room name starts as Room. The room holds 128 posts.
  • The room admin password starts as password. Change it before you use the room.
  • The guest password starts blank.
  • Repeat is off until you turn it on.
  • Logger is on, every 15 minutes. Solar is set to auto.
  • Bluetooth pairing PIN is 123456.
  • TX is capped at 22 dBm into the SX1262. There is no external PA on the RAK4631 WisBlock.

Companion+repeat, jp.crep1

  • Repeat is off until you turn it on, or until One Stop’s Camp Mode switch turns it on.
  • Logger is on, every 15 minutes, 256 records.
  • Solar is set to auto. If no INA3221 is present, solar sampling stays quiet.
  • Bluetooth pairing PIN is 123456. On the Seeed XIAO nRF52840 + Wio-SX1262 the name is MeshCore- plus the node name.
  • On the Heltec T096, set tx is the SX1262 value, from -9 to 22. 22 into the onboard PA is about 28 dBm at the antenna. The compiled default is 9, about 22 dBm at the antenna. GPS is compiled out, and the receiver stays off.
  • On the RAK4631 WisBlock, TX is capped at 22 dBm into the SX1262. There is no external PA on that board.

Repeater, jp.wdt2

  • Repeat is on. This is a repeater.
  • Logger is on, every 15 minutes, 256 records.
  • Solar is set to auto and uses an INA3221 when one is found. If the chip does not answer, those fields stay at zero for that sample.
  • USB serial is 115200. Bluetooth is a Nordic UART named RPT- plus the node name. Pairing PIN is 123456. After you pair, log in with your admin password before using the commands below.
  • On the Heltec T096, the compiled node name is ORD Water Tower. set tx is the SX1262 value, from -9 to 22. 22 into the onboard PA is about 28 dBm at the antenna. The compiled default is 9, about 22 dBm at the antenna. GPS is compiled out, and the receiver stays off.
  • On the RAK4631 WisBlock, TX is capped at 22 dBm into the SX1262. There is no external PA on that board.

Commands

These text commands work on jp.wdt2 and jp.crep1, and on the companion side of jp.croom1. On a companion, send them over the companion link. On a repeater, use USB serial or the Bluetooth CLI after login. Frequency and TX also follow the companion or repeater commands for those settings.

ver
get repeat
set repeat on
set repeat off
set freq 869.618
set tx 9
get logger
set logger on
set logger off
set logger.interval 15
logger latest
logger page 0
logger clear
get solar
set solar auto
set solar on
set solar off
solar
get watchdog
power
stats-core
stats-radio
stats-packets

logger page 0 is the newest record. set logger.interval is in minutes. set tx is the SX1262 value, not the antenna power. On the Heltec T096 it must stay in the range -9 to 22. On the RAK4631 WisBlock it is capped at 22.

These extra commands are for jp.croom1 on the RAK4631 WisBlock:

get room
set room on
set room off
set room.name My Room
set room.guest
set room.guest hello
set room.password secret
room.post hello from the desk

Change the room admin password from the default password before you use the room.
