Firmware

These images are C.B.H.B. builds on top of MeshCore v1.18.0. Use the files on this page, not a copy sent by someone else.

Test builds

Flash notes

  • XIAO (UF2). Double-tap the reset button so the board shows up as a drive, then copy the .uf2 file onto it. The board’s filesystem is not erased.
  • Heltec V3 (merged bin). Flash the merged .bin at offset 0x0. Use this merged file, not a separate app-only image.

Defaults

Companion+repeat, jp.crep1

  • Repeat is off until you turn it on, or until One Stop’s Camp Mode switch turns it on.
  • Logger is on, every 15 minutes, 256 records.
  • Solar is set to auto. If no INA3221 is present, solar sampling stays quiet.
  • Bluetooth pairing PIN is 123456. On the XIAO the name is MeshCore- plus the node name. On Heltec V3, the PIN is shown on the screen the first time if one has not been saved yet.

Repeater, jp.wdt2

  • Repeat is on. This is a repeater.
  • Logger is on, every 15 minutes, 256 records.
  • Solar is set to auto and uses an INA3221 when one is found. If the chip does not answer, those fields stay at zero for that sample.
  • USB serial is 115200. Bluetooth is a Nordic UART named RPT- plus the node name. Pairing PIN is 123456. After you pair, log in with your admin password before using the commands below.

Commands

These text commands work on both jp.wdt2 and jp.crep1. On the companion, send them over the companion link. On the repeater, use USB serial or the Bluetooth CLI after login.

ver
get repeat
set repeat on
set repeat off
get logger
set logger on
set logger off
set logger.interval 15
logger latest
logger page 0
logger clear
get solar
set solar auto
set solar on
set solar off
solar
get watchdog
power
stats-core
stats-radio
stats-packets

logger page 0 is the newest record. set logger.interval is in minutes.
