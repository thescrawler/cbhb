Firmware v1.18.0-jp.croom1, RAK4631 WisBlock

November 13, 2026 · companion+room · RAK4631 WisBlock · test build

Based on upstream MeshCore v1.18.0. This file is only for the RAK4631 WisBlock (RAK19003 base). It has not been tested on radio hardware yet.

  • BLE companion with a room server on a second identity. The room is off by default; turn it on with set room on.
  • The room admin password starts as password. Change it before you use the room. The room holds 128 posts.
  • Repeat is off until you turn it on. Logger is on, every 15 minutes. Solar is set to auto.
  • TX is capped at 22 dBm into the SX1262. There is no external PA on this board. The compiled default frequency is 869.618 MHz, until you change it in the app or with set freq.

Firmware v1.18.0-jp.crep1, Heltec T096

November 13, 2026 · companion+repeat · Heltec T096 · test build

Based on upstream MeshCore v1.18.0, built with the upstream heltec_t096 target. This file is only for the Heltec T096. It has not been tested on radio hardware yet.

  • BLE companion that can also forward flood traffic, using MeshCore’s client-repeat path and repeater hop limits. Repeat is off by default.
  • Data logger on, every 15 minutes, 256 records. Solar set to auto, and quiet when no INA3221 is present.
  • set tx is the SX1262 value, from -9 to 22. 22 into the onboard PA is about 28 dBm at the antenna. The compiled default is 9, about 22 dBm at the antenna.
  • GPS is compiled out, and the receiver stays off. The compiled default frequency is 869.618 MHz, until you change it in the app or with set freq. Bluetooth pairing PIN is 123456.

Firmware v1.18.0-jp.wdt2, Seeed XIAO nRF52840 + Wio-SX1262

November 13, 2026 · repeater · Seeed XIAO nRF52840 + Wio-SX1262 · test build

Based on upstream MeshCore v1.18.0. This build has not been tested on radio hardware yet.

  • Keeps the 45-second, sleep-running hardware watchdog and the paired Bluetooth CLI from v1.18.0-jp.wdt.
  • Adds a data logger: on by default, every 15 minutes, 256 records.
  • Adds INA3221 solar sampling, default auto. If the chip is missing, those fields stay at zero and sampling stays quiet.
  • Text commands to turn repeat, logger, and solar on or off, and to read or clear the log. The compiled default frequency is 869.618 MHz, until you change it in the app or with set freq.

One Stop 99.1.6

November 12, 2026 · Android sideload

First sideload build hosted as a download on this site. Replaced as the current build by 99.1.7 on November 13, 2026, and kept here for rollback. 99.1.7 uses a new signing key, so going between 99.1.6 and 99.1.7 either way needs an uninstall first. Uninstalling clears saved devices, which you will have to add again.

  • My Devices, with a phone-only display name, Request status, ping, and login.
  • Voltage readings and a trend, plus a battery percent estimate, when you ask.
  • Settings export (passwords and the private key left out), a per-device CSV log, and GPX export for saved locations.
  • Map layers from public feeds, kept separate from mesh messages.
  • Remote retune for a radio you own, and app themes.

Download One Stop 99.1.6

Firmware v1.18.0-jp.wdt, Seeed XIAO nRF52840 + Wio-SX1262

November 8, 2026 · repeater · Seeed XIAO nRF52840 + Wio-SX1262

Based on upstream MeshCore v1.18.0. This is the earlier Seeed XIAO nRF52840 + Wio-SX1262 repeater image, kept for rollback from jp.wdt2 on that same board.

  • 45-second, sleep-running hardware watchdog on the Seeed XIAO nRF52840.
  • Atomic writes for prefs, ACL, and identity.
  • Paired Bluetooth CLI (Nordic UART), pairing PIN 123456.

It does not include the data logger or INA3221 solar sampling added in jp.wdt2.
