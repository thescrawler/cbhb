Release notes

Newest first. Each new MeshCore One Stop build, and each new C.B.H.B. firmware build, gets an entry on this page. Downloads are on the One Stop and firmware pages. To build a node that uses these features, see Build a Solar Logging Node and Set up Camp Mode.

One Stop 99.1.7

November 13, 2026 · Android sideload · test build

This build has not been tested on radio hardware yet. It is signed with a new key, so uninstall the old One Stop first, then install this file. Uninstalling clears saved devices, which you will have to add again.

  • Repeat (Camp Mode) switch, for companion firmware jp.crep1.
  • Remote logger and solar on/off, plus a data log viewer with a chart and CSV export, for repeater firmware jp.wdt2.

Firmware v1.18.0-jp.crep1

November 13, 2026 · companion+repeat · XIAO nRF52840 + Wio-SX1262 and Heltec V3 · test build

Based on upstream MeshCore v1.18.0. This build has not been tested on radio hardware yet.

  • BLE companion that can also forward flood traffic, using MeshCore’s client-repeat path and repeater hop limits.
  • Repeat is off by default, until you turn it on or One Stop’s Camp Mode switch turns it on.
  • Data logger on, every 15 minutes, 256 records. Solar set to auto, and quiet when no INA3221 is present.
  • Same text commands as the jp.wdt2 repeater for repeat, logger, and solar. Bluetooth pairing PIN is 123456.
  • Heltec image is a merged .bin, flashed at offset 0.

Download for XIAO · Download for Heltec V3

Firmware v1.18.0-jp.wdt2

November 13, 2026 · repeater · XIAO nRF52840 + Wio-SX1262 · test build

Based on upstream MeshCore v1.18.0. This build has not been tested on radio hardware yet.

  • Keeps the 45-second, sleep-running hardware watchdog and the paired Bluetooth CLI from v1.18.0-jp.wdt.
  • Adds a data logger: on by default, every 15 minutes, 256 records.
  • Adds INA3221 solar sampling, default auto. If the chip is missing, those fields stay at zero and sampling stays quiet.
  • Text commands to turn repeat, logger, and solar on or off, and to read or clear the log.

Download jp.wdt2 · Previous versions

One Stop 99.1.6

November 12, 2026 · Android sideload

First sideload build hosted as a download on this site. Replaced as the current build by 99.1.7 on November 13, 2026, and kept here for rollback. 99.1.7 uses a new signing key, so going between 99.1.6 and 99.1.7 either way needs an uninstall first. Uninstalling clears saved devices, which you will have to add again.

  • My Devices, with a phone-only display name, Request status, ping, and login.
  • Voltage readings and a trend, plus a battery percent estimate, when you ask.
  • Settings export (passwords and the private key left out), a per-device CSV log, and GPX export for saved locations.
  • Map layers from public feeds, kept separate from mesh messages.
  • Remote retune for a radio you own, and app themes.

Download One Stop 99.1.6

Firmware v1.18.0-jp.wdt

November 8, 2026 · repeater · XIAO nRF52840 + Wio-SX1262

Based on upstream MeshCore v1.18.0. This is the earlier XIAO repeater image, kept for rollback from jp.wdt2.

  • 45-second, sleep-running hardware watchdog on the nRF52840.
  • Atomic writes for prefs, ACL, and identity.
  • Paired Bluetooth CLI (Nordic UART), pairing PIN 123456.

It does not include the data logger or INA3221 solar sampling added in jp.wdt2.

Download jp.wdt
