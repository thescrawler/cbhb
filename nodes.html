Boardman and Hermiston · about 20 miles apart

Node map

This is the public MeshCore map, opened around Boardman and Hermiston. The radios on it are the ones that reached map.meshcore.io. This website does not keep its own list and does not add positions.

Tap a radio on the map for its name and when it was last heard. A position is whatever that radio advertised. It may be approximate. A radio that stays on a local mesh and never reaches the public map will not appear.

When this site states a distance, it is in miles. Boardman and Hermiston are about 20 miles apart. The map below may use its own scale.

If the map is blank

Use Open the MeshCore map. That is the same public map, in its own page. The large node list behind it is not readable from a plain website like this one, so this page shows the map itself instead of copying numbers.

Meshtastic

Mesh Tools can also show Meshtastic radios, using the public list at meshmap.net. Only radios that reach the internet are on that list. This page does not copy those positions. Open meshmap.net, or use Mesh Tools on aprs.fi, to see them.

Same sources as Mesh Tools

Mesh Tools reads MeshCore nodes from map.meshcore.io/api/v1/nodes and Meshtastic nodes from meshmap.net/nodes.json. The map on this page is that MeshCore map, so you are looking at the same public MeshCore feed, drawn by the map’s own site.
