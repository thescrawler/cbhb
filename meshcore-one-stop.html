MeshCore One Stop

MeshCore One Stop is an app designed to bring all of your MeshCore needs to one location.

Install and pair

The app is not on the Play Store yet. Get the APK from a C.B.H.B. admin and install it on a 64-bit Android phone running Android 7 or later.

  1. On that phone, get the APK from a C.B.H.B. admin.
  2. Open the file. If Android says it is not allowed to install from this source, allow installs from the browser or the Files app you used, then open the file again. That permission is only for that one source, not for every app on the phone.
  3. Google Play Protect may say it does not recognize the app, because this build is not from the Play Store. That warning is expected. If you are sure you got the file from a C.B.H.B. admin, you can choose to install anyway. If you are not sure, do not install it.
  4. Finish the install and open MeshCore One Stop.

After it is installed, the app connects to your own MeshCore radio in one of three ways:

  • Bluetooth. Wireless, the way a phone connects to a speaker or a headset. If Bluetooth is off, the app will tell you. Android may ask for nearby-device or location permission so it can scan for the radio.
  • USB. A cable between the phone and the radio. The radio needs USB companion firmware. If the phone asks for USB permission, allow it. You may need a USB-OTG adapter, depending on the phone.
  • TCP. A network address, if the radio is already reachable that way.

Messages go through that radio onto the mesh. If the phone is not connected to the radio, the app cannot send chat for you.

My Devices

My Devices is your list of radios on this phone. You can add a radio to the list or remove it. You can give a radio a display name that lives only on your phone. Examples: C.B.H.B. Node (1) or C.B.H.B. Node (Patterson).

That name helps you tell radios apart in the app. It does not change the name that goes out over the air.

Opening the list, or pulling down to refresh, does not radio the repeater. The list shows the last saved readings. To get a new reading, open a device and tap Request status. That sends one status request.

From a device you can also:

  • Ping repeater. Check that the radio is reachable, and see a distance and signal reading when the ping gets through.
  • Log in. Use the admin password, and save it on the phone if you want the app to keep it. A guest login cannot change the channel. If no password is saved, the app will ask you to log in from Contacts or My Devices and save it.

These are the same kinds of actions that are on Contacts. Status and ping do not require a login. Changing radio settings does.

Telemetry

A reading is taken when you open a device and tap Request status. The list itself does not ask the radio, and the app does not keep asking in the background.

You see voltage, and whether that voltage is trending up or down since the last saved reading. The battery percent is an estimate from the voltage. It is not a separate battery gauge.

Each reading can also record the radio settings that came back with it, including frequency, bandwidth, spreading factor, and coding rate. Those readings stay in the per-device log on the phone.

If you have just added a device and have not requested status yet, the app will say there are no pulls yet, and tell you to tap Request status for one reading.

Export and logs

You can export settings. That export leaves out passwords and the private key.

You can also save a CSV log for each device. The log stays on the phone unless you choose to share the file yourself.

If a contact or a repeater has a location, you can export those points to a GPX file, for use in a map program. That file is also made on the phone. Exporting it does not upload it to C.B.H.B.

Map and messages

Chat and other off-grid messages travel only while the phone is connected to your radio by Bluetooth, USB, or TCP. Mesh messages stay on the radio. They do not go through the internet.

The map is a different path. Map and status layers can download public feeds:

  • MeshCore nodes
  • Meshtastic nodes
  • FT8, when you ask for it (on demand, not by itself)
  • Winlink reports sent from WINLINK to APWL2K

The phone keeps the last good download so you can look at it again. Those feeds come from the internet. They are not the same path as your mesh messages.

Remote retune

If you own a repeater, the app can retune that radio from the phone. On My Devices, tick one or more owned repeaters and tap Radio. Set frequency in MHz, bandwidth, spreading factor, and coding rate.

  • Save as main first if this is the channel you want to come home to. That stores the setup as the one you can return to.
  • Restore main fills the form back in with that saved setup. You still apply it the same way.
  • Apply asks you to confirm before it changes the radio.
  • The repeater reboots onto the new settings. Expect it to drop offline for a moment. It drops off this companion until the companion is on the same frequency, bandwidth, spreading factor, and coding rate.
  • You can let the app retune the companion in that same step, or leave the companion where it is and match it yourself from the radio settings. Transmit power is not changed.
  • This needs the admin password saved from a previous login. A guest login cannot change the channel.

Save a main preset first if you need a way back. The repeater drops until this companion matches.

Themes

The app has four looks: Day, Night, OLED, and Auto. You can also create your own theme, give it a name, and copy or import a theme code. A dark background makes a dark theme. These choices are only how the app looks on your phone. They do not change the radio.
