Guides

Short guides and the current downloads. The Mesh Tools steps follow the project’s own install page. The app, firmware, solar logging node, and Camp Mode steps are on this site. Firmware and release notes are kept with each new build. The tester steps stop where the Play Store link still has to go.

  • Install Mesh Tools Put the aprs.fi panel on a phone or a computer with Tampermonkey. Version 1.6.3-beta.
  • Use MeshCore One Stop Install sideload 99.1.7, connect the Android app to your radio, and read voltage when you ask. This is a test build.
  • Build a Solar Logging Node Parts, drawings, wiring, and setup for jp.wdt2 on the Seeed XIAO nRF52840 + Wio-SX1262, with an INA3221 solar log, viewed in One Stop 99.1.7.
  • Set up Camp Mode Flash jp.crep1 on the Seeed XIAO nRF52840 + Wio-SX1262 and use the Repeat (Camp Mode) switch in One Stop 99.1.7.
  • Firmware Test builds jp.wdt2, jp.crep1, and jp.croom1 for the Seeed XIAO nRF52840 + Wio-SX1262, RAK4631 WisBlock (RAK19003 base), and Heltec T096, with flash notes and commands.
  • Release notes What changed in each app and firmware build, newest first.
  • Become a tester What to have ready for the Play Store closed test. The join link is not live yet.
