Guide

Become a tester

MeshCore One Stop needs 12 testers for 14 days. Closed testing on the Play Store is not open yet, so these steps end at an empty link.

Before you start

  1. Use an Android phone.
  2. Use the Gmail account that is on that phone.
  3. Plan to leave the app installed for 14 days.

When the link is posted

  1. Open Become a tester on the Android phone you will use.
  2. Find the box labeled “Play Store tester join link.” Today that box says “Link goes here.”
  3. When a real Play link replaces that line, tap it.
  4. Sign in with Gmail if Google asks, and join the test.
  5. Install MeshCore One Stop from the Play Store page Google opens.
There is no join link yet

The Play Store test join spot will be the box on the tester page. Until that test is open, install the current sideload build from the MeshCore One Stop page. Do not install a file from a text message or a private shared folder.

After it is installed, the app guide says how the phone connects to a radio. The privacy policy says what stays on the phone.
