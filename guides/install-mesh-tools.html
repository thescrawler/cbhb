Install Mesh Tools

aprs.fi Mesh Tools is a userscript: a small extra that a browser add-on runs on aprs.fi. It is not its own app on your home screen. You install Tampermonkey once, then install this script into it. After that, opening aprs.fi is enough.

These steps follow the project’s Installation page and What is Tampermonkey?. The script only runs on aprs.fi. Turning it off puts aprs.fi back the way it was. Your aprs.fi account is never changed.

On a phone (usual way)

Chrome on a phone cannot run extensions, so Tampermonkey will not work there. On Android, use Firefox. Edge also works. Kiwi Browser can run it, but Tampermonkey says Kiwi is no longer updated, so Firefox or Edge is safer.

Firefox on Android is the usual way. Copy this link, open Tampermonkey’s Utilities page, then use Import from URL.

https://raw.githubusercontent.com/thescrawler/aprsfi-mesh-tools/main/aprsfi-mesh-tools.user.js
  1. Long-press the link and choose Copy link (or copy it from the box).
  2. In Firefox, tap the menu (the three dots), then Extensions. Older Firefox says Add-ons. Tap Tampermonkey. If you already see a Tampermonkey icon, tap that instead.
  3. Tap Dashboard.
  4. At the top of the Dashboard, tap the Utilities tab. On a small screen those tabs sit in a row you can slide sideways until Utilities shows. Tampermonkey’s own help says: if that tab is missing, set Config mode to Beginner or Advanced.
  5. Find Import from URL, paste the link, and tap Install.
  6. Tap Install again on the next page.

If Tampermonkey is not in Firefox yet: tap the three dots, then Extensions, and search for Tampermonkey.

Edge and Kiwi on Android

Install Firefox or Microsoft Edge from the Play Store, then add Tampermonkey. In Edge tap the menu, then Extensions, and add Tampermonkey. Kiwi is usually the same path as Edge. Then use the same link and the same Utilities page:

  • Edge: usually the menu, then Extensions, then Tampermonkey, then Dashboard.
  • Kiwi: usually the same path. Firefox or Edge is safer.

On a small screen, slide the tab row until Utilities shows. If that tab is missing, set Config mode to Beginner or Advanced.

iPhone or iPad

iPhone and iPad support is new and less tested. If something does not work, tell the project at GitHub Issues.

  1. Install the Tampermonkey app from the App Store.
  2. Open Settings, then Safari, then Extensions. On newer iOS: Settings, Apps, Safari, Extensions. Turn on Tampermonkey and set it to Allow on All Websites.
  3. Long-press the link in the box above and choose Copy link.
  4. In Safari, open Tampermonkey and tap Dashboard. This is usually the puzzle-piece or aA button, then Tampermonkey, then Dashboard.
  5. Tap the Utilities tab. Slide the tab row if you need to. If the tab is missing, set Config mode to Beginner or Advanced.
  6. Find Import from URL, paste the link, tap Install, then tap Install again.
  7. Open aprs.fi.

Another browser on the iPhone only works if it can run the same extension. Bluefy, for example, is a Bluetooth browser and does not have Tampermonkey’s Dashboard.

On a computer

Google Chrome

  1. Open the Tampermonkey page on the Chrome Web Store and click Add to Chrome, then Add extension.
  2. Turn on Allow User Scripts. Click the puzzle-piece Extensions icon, then the menu next to Tampermonkey, then Manage extension. You can also type chrome://extensions and click Details under Tampermonkey.
  3. Turn on Allow User Scripts. On older Chrome that switch is not there. Turn on Developer mode instead, at the top of chrome://extensions.

If the script is installed but the panel never appears, the missing Allow User Scripts or Developer mode switch is the most common cause.

Microsoft Edge

  1. Open Tampermonkey on Edge Add-ons and click Get.
  2. Go to edge://extensions. Under Tampermonkey, click Details and turn on Allow User Scripts. If that is not shown, turn on Developer mode.

Firefox

Open Tampermonkey on Firefox Add-ons, then click Add to Firefox and Add. No extra switch is needed.

Then install the script

  1. Click Install aprs.fi Mesh Tools.
  2. Tampermonkey opens an install screen showing aprs.fi Mesh Tools (beta). Click Install.
  3. Open or reload aprs.fi. Wait a couple of seconds. The Mesh Tools panel appears in the bottom-right corner.

If the link only shows code

You are in a browser that does not have Tampermonkey. On a phone that is often Chrome. Open the link in the browser where Tampermonkey is installed, or use Import from URL as in the phone steps above.

The first time it downloads data

Tampermonkey may ask whether the script can connect to another website. The script only connects to these four sites, which are named in its header:

Site Why
map.meshcore.io List of MeshCore radios
meshmap.net List of Meshtastic radios
s3.amazonaws.com Terrain (hill height) tiles for coverage
retrieve.pskreporter.info FT8 spots, and only after you tap Fetch FT8 now

Choose Always allow (or Always allow domain) for each. Nothing about you is uploaded. Details are in Privacy and data sources.

First time on the map

  1. Open aprs.fi in the same browser where Tampermonkey is installed.
  2. A white Mesh Tools panel appears in the bottom-right corner. Read the welcome tip and tap Got it.
  3. Zoom in. MeshCore radios appear as colored diamonds. Meshtastic radios appear as green dots with an M. Further out than about a state or region, the line says to zoom in closer.
  4. Tap a red repeater diamond. In its popup, tap Show coverage. After a few seconds, a shaded area shows where it can probably reach. Green is a strong guess, yellow is fair, and orange is weak. Trees and buildings are not included.
  5. Open the Coverage tab and tap Drop a pin to test a spot, then tap the map, to try a place with no repeater.
  6. Tap any small round info button in the panel for a one-line explanation of that setting.

The panel remembers the last tab. Tap the title bar to fold it. Drag the drag to move bar if it covers something. Double-tap that bar, or tap the reset control, to send it back to the corner. Miles are the default distance unit. You can switch to kilometers on the Coverage tab.

More on each tab is in the project guide: Mesh nodes, Coverage, Map layers, and FAQ.

Old separate scripts

Mesh Tools replaces three older scripts:

  • aprs.fi MeshCore + Meshtastic Overlay
  • aprs.fi MeshCore Coverage Overlay
  • aprs.fi Map Layer Toggles

If one of them is still running, that part of Mesh Tools stays off so nothing is drawn twice. You will see a yellow notice that old scripts are still on. Open the Tampermonkey Dashboard, switch those old scripts off (or delete them), and reload aprs.fi.

Updates, and taking it off

Tampermonkey checks for updates from this GitHub repository, about once a day. To update now, open the Dashboard, select aprs.fi Mesh Tools (beta), and choose Trigger update. You can also open the install link again. Your settings, pins, and saved coverage stay.

The version number is at the bottom of the panel, under panel settings. It should read 1.6.3-beta. Help / Wiki there opens the project guide.

To remove the script, open the Dashboard and use the trash control next to aprs.fi Mesh Tools (beta). That also removes its saved settings. aprs.fi itself is not changed.

If the panel never shows, the project’s Troubleshooting page is the place to look. The usual causes are the script switch being off, a phone browser without Tampermonkey, or Allow User Scripts still off on a computer.
