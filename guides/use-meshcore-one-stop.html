Guide

Use MeshCore One Stop

MeshCore One Stop is an app designed to bring all of your MeshCore needs to one location. Package name com.cbhb.meshcoreonestop. These steps are for the current sideload build, 99.1.7, a test build. Longer notes live on the app page.

1. Install the app from this site

Public listings on Google Play, GitHub releases, and F-Droid are not up yet. The closed Play Store test is not open yet either. For now, install the APK from this website on a 64-bit Android phone running Android 7 or later. 99.1.7 is a test build and has not been tested on radio hardware yet. It is signed with a new key, so uninstall the old One Stop first. That clears saved devices, which you will have to add again.

  1. On that phone, open the MeshCore One Stop page and tap Download MeshCore One Stop 99.1.7.
  2. Open the downloaded file. If Android says it is not allowed to install from this source, allow installs from the browser or the Files app you used, then open the file again.
  3. Play Protect may say it does not recognize the app, because this build is not from the Play Store. That warning is expected. If you downloaded the file from this site, you can choose to install anyway. The SHA-256 checksum on the app page is for the official file.
  4. Finish the install and open the app.

When the Play Store test opens, that path will be on Become a tester.

2. Connect your radio

The app talks to the radio over Bluetooth, a USB cable, or TCP (a network address). Chat only moves while that connection is up. If Bluetooth is off, turn it on. For USB, the radio needs USB companion firmware, and the phone may ask for USB permission. Details: Install and pair.

3. Name it on the phone, if you want

Add the radio to My Devices if it is not already there. A local display name such as “C.B.H.B. Node (1)” or “C.B.H.B. Node (Patterson)” is only on your phone. The on-air name stays as it is. Details: My Devices.

4. Read voltage when you ask

Opening My Devices, or pulling down to refresh, shows the last saved readings. It does not radio the repeater. Open a device and tap Request status for one new reading. You get voltage and the trend. The battery percent is estimated from that voltage. The app does not keep checking in the background. You can also ping the repeater to see if it is reachable, and log in to save an admin password. Details: Telemetry.

5. Save a log or settings, if you need them

Settings export leaves out passwords and the private key. A CSV log is per device and stays on the phone until you share the file. If a contact or a repeater has a location, you can also export those points to a GPX file. If the radio is running repeater firmware jp.wdt2, 99.1.7 can also pull the radio’s data log, show it as a chart, or save it as CSV. Details: Export and logs.

6. Treat the map and the messages as two paths

Messages need the radio connection. They stay on the mesh and do not go through the internet. Map layers may download public feeds (MeshCore nodes, Meshtastic nodes, FT8 when you ask, and Winlink reports from WINLINK to APWL2K) and keep the last good download on the phone. Details: Map and messages.

7. Retune only a radio you own

On My Devices, tick one or more owned repeaters and tap Radio. Set frequency, bandwidth, spreading factor, and coding rate. Use Save as main first if this is the channel you want to come home to. Restore main fills the form back in; you still apply it the same way. The app asks you to confirm. The radio reboots and drops off until the companion is on the same settings. You can retune the companion in that same step, or match it yourself. Transmit power is not changed. This needs a saved admin password. A guest login cannot change the channel. Details: Remote retune.

Day, Night, OLED, and Auto are the themes. You can also create, copy, or import a theme. The privacy policy says what stays on the phone. What’s new in 99.1.7, and the matching firmware, are on the release notes and firmware pages.
