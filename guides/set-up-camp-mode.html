Guide

Set up Camp Mode

Camp Mode lets a companion radio also forward flood traffic for other people around you. It uses companion firmware jp.crep1 and the Repeat (Camp Mode) switch in One Stop 99.1.7.

Test builds

Firmware jp.crep1 and One Stop 99.1.7 have not been tested on radio hardware yet. Bench-test on a spare radio first.

1. Flash jp.crep1

Pick the file for your board on the firmware page. Repeat is off until you turn it on.

  • XIAO nRF52840 + Wio-SX1262. Download the jp.crep1 UF2. Double-tap reset, then copy the file onto the board.
  • Heltec LoRa32 V3. Download the merged .bin and flash it at offset 0 (0x0).

The Bluetooth pairing PIN is 123456. On the XIAO the name is MeshCore- plus the node name. On Heltec V3, the PIN is shown on the screen the first time if one has not been saved yet.

2. Install One Stop 99.1.7

Download One Stop 99.1.7 from the app page. This build is signed with a new key, so uninstall an older One Stop first. That clears saved devices, which you will have to add again.

3. Turn Camp Mode on

  1. Open the app and connect to the companion radio.
  2. Use the Repeat (Camp Mode) switch to turn forwarding on.
  3. Leave it on only while you want this radio to help pass traffic. Turn it off when you do not.

You can also use the text commands set repeat on and set repeat off over the companion link. get repeat shows the current state.

What stays the same

  • Messages addressed to this radio are still kept for the phone. They are not re-sent as a repeat.
  • Logger and solar defaults are the same as the other jp.crep1 notes on the firmware page: logger on, solar auto.
  • If you also want a solar logging repeater, that is a different build, with jp.wdt2: Build a Solar Logging Node.

Full change lists are on the release notes page.
